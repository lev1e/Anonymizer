# Office add-in и папки: дизайн

Дата: 2026-10-02. Статус: согласован с пользователем в диалоге, реализуется.

## Цель
1. Add-in для Word, Excel, PowerPoint (Windows и Mac): кнопка обезличивает **открытый документ на месте**,
   вторая кнопка возвращает исходные значения из того же зашифрованного хранилища.
2. Отдельная программа остаётся без потерь функций.
3. Пакетная обработка **целой папки** (обезличить и восстановить) в отдельной программе.
4. Ничего не жертвуется: те же метки, то же хранилище, те же инварианты (ARCHITECTURE.md §11).

## Решения
- Один процесс и одно хранилище. Add-in не содержит логики распознавания: панель шлёт байты открытого файла локальному
  движку (`Service.anonymize` / `Service.restore`) и вставляет результат вместо содержимого документа.
- Ограничение Office.js: нет вызова «заменить файл целиком». Используются
  Word `body.insertFileFromBase64(..., "Replace")`, PowerPoint `insertSlidesFromBase64` + удаление старых слайдов,
  Excel `insertWorksheetsFromBase64` + удаление старых листов. Поэтому добавлены три защиты:
  1. **Зашифрованная копия оригинала** до замены (ключ устройства), кнопка «Откатить».
  2. **Проверка после замены**: панель заново читает документ, движок сверяет его с ожидаемым результатом
     (тексты, число листов/слайдов, имена листов) и называет расхождения.
  3. **Режим «копия рядом»** (скачать обезличенный файл, оригинал не трогать), если замена на месте недоступна.
- Транспорт: HTTPS на `127.0.0.1:47831`, сертификат выдаёт локальный CA с ограничением имён (только localhost и 127.0.0.1),
  устанавливается в доверенные для пользователя. Страница add-in отдаётся тем же сервером (тот же origin, CORS не нужен).
  Проверки: `Host`, `Origin`/`Sec-Fetch-Site`, заголовок `X-Requested-With`, токен установки.
- Фоновый режим: `Anonymizer --background` поднимает окно скрытым; закрытие окна прячет его, пока включено «работать в фоне».
  Повторный запуск показывает окно. Без опроса и таймеров: процесс простаивает (0% CPU).
- Папки: рекурсивный обход, один проход обучения на все файлы (одна сущность — одна метка), результат в зеркальную папку
  `Папка{N} (обезличено)` с нейтральными именами подпапок и файлов; неподдерживаемые файлы пропускаются и перечисляются.
  Возврат папки: `... (восстановлено)`. Один плохой файл не роняет задание.
- Установка: `Anonymizer --install-addin` (сертификат, manifest, регистрация), `--uninstall-addin`.
  Windows: `HKCU\Software\Microsoft\Office\16.0\WEF\Developer`, Mac: `~/Library/Containers/com.microsoft.<App>/Data/Documents/wef`.

## Компоненты
| Файл | Назначение |
|---|---|
| `anonymizer/certs.py` | CA + сертификат localhost, установка доверия |
| `anonymizer/addin.py` | API add-in: задания, копия оригинала, проверка, откат; HTTPS-сервер |
| `anonymizer/addin_install.py` | manifest, регистрация по ОС |
| `anonymizer/folders.py` | обход папки, зеркальный вывод, нейтральные имена каталогов |
| `anonymizer/addin_web/*` | `taskpane.html`, `taskpane.js`, `taskpane.css`, `manifest.xml.tmpl`, иконки |
| `anonymizer/desktop.py` | `--background`, `--install-addin`, скрытие окна, мост выбора папки |
| `anonymizer/webapp.py` + `web/index.html` | задания по папке, кнопка «Выбрать папку» |

## Ошибки и честность
- Нет связи с движком → панель говорит об этом и ничего не меняет.
- Файл не обезличен/не прошёл проверку → документ не заменяется.
- Расхождения после вставки показываются списком; доступен откат.
- Чужое хранилище при возврате → отказ (как сейчас).

## Тесты
- Python: API add-in (байты туда и обратно, отказ по Host/Origin/токену), копия оригинала и откат, проверка после замены,
  папки (структура, обучение между файлами, плохой файл, нейтральные имена), сертификаты, manifest.
- Реальный Office на Mac: полный цикл Word/Excel/PowerPoint.
